# ZaminMC Development

ZaminMC builds software for the Minecraft ecosystem — a modern server engine, server management tooling, client-side addons, and community resources.

> *Ending the monopoly of the Minecraft ecosystem.*

## Public projects

| Project | About |
| --- | --- |
| [ZaminTorch](https://github.com/ZaminMC/ZaminTorch) | A modern Minecraft server engine built around a stable API, parallel execution, and compatibility from 1.8.8 to the latest versions. |
| [ZIM](https://github.com/ZaminMC/ZIM) | Zamin Instances Manager — a desktop panel, CLI, and resident daemon for running and managing Minecraft servers. |
| [ZEA](https://github.com/ZaminMC/ZEA) | Zamin's EarthMC Addon — an all-in-one client-side Fabric addon for EarthMC, featuring enhanced chat, gameplay utilities, integrations, and community tools. |
| [ZEA-REPO](https://github.com/ZaminMC/ZEA-REPO) | A community-driven repository for ZEA, providing curated EarthMC data, shared configurations, and community-maintained resources. |
| [docs](https://github.com/ZaminMC/docs) | Documentation for all projects under the ZaminMC umbrella. |
| [Anchor](https://github.com/ZaminMC/Anchor) | See the repository for details. |
